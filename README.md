# 🦷 Baidyanath Dental Clinic - Official Landing Page

A sleek, responsive, and high-performance landing page developed for **Baidyanath Dental Clinic** located in Lucknow. 

## 🌟 Overview
This web application provides a seamless digital presence for the clinic, featuring patient testimonials, interactive FAQs, treatment highlights, and quick WhatsApp/Call appointment options.

## 🛠️ Tech Stack
- **Framework:** React with TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Bundler:** Vite
